# Contributing

Issues and pull requests are welcome.

- Keep `SKILL.md` under 500 lines; put detail in `references/`.
- Prompts describe technique only. Never add film, studio or artist names to prompt templates; credits go in `references/13-credits-and-style.md`.
- No model weights, no large media, no personal paths or credentials. Example images must be your own and under about 500 KB.
- Run `python3 -m pytest -q tests` before opening a pull request.
