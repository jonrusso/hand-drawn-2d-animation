# Security

This skill is markdown plus local Python scripts. It stores no credentials and makes no network calls of its own; generation happens in the tools you connect (for example CapCut).

If you find a security issue (a script that could run untrusted input, a leaked secret, an unsafe default), please open a private report through GitHub's "Report a vulnerability" button on the Security tab instead of a public issue.

Never paste API keys, tokens, signed URLs or account details into issues, prompts or example files.
